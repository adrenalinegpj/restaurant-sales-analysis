# Restaurant Sales Analysis

## Project Overview

This project analyzes restaurant sales data to uncover meaningful insights about sales performance, revenue trends, customer behavior, menu categories, and payment preferences. The analysis uses Python to clean, explore, and visualize the data to support better business decisions.

---

## Business Objectives

This project aims to answer the following questions:

- How does revenue change over time?
- Which menu categories generate the most revenue?
- Which items are the most popular and profitable?
- Who are the top customers based on total revenue?
- Is there a relationship between item price and quantity ordered?
- What is the typical size of an order?
- Which payment methods do customers prefer?

---

## Tools & Technologies

- **Python**
- **Pandas** – Data cleaning and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
